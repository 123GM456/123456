# Excel 图表代码实现（数据可视化课程作业）

用 **Python + pyecharts** 将《Excel数据可视化——从图表到数据大屏》（清华大学出版社）配套示例中的全部图表用代码复现，数据与 Excel 原始文件一致。

## 环境要求

- Python 3.8+
- pyecharts（安装：`pip install -r requirements.txt`）

## 运行方法

在项目根目录执行：

```bash
# 第二章：30 张静态图
python chapter2/chart01_渐变柱形图.py
# ...（每个文件独立运行，生成对应 HTML 到 output/）

# 第三章：7 张动态图
python chapter3/chart01_动态柱形图.py

# 第四章：2 个看板
python chapter4/chart01_人力资源看板.py
```

生成的 HTML 在 `output/` 目录，浏览器直接打开即可查看。总览入口：`index.html`。

> 每个图表页面底部已加"上一张 / 下一张"导航按钮。如果重跑过图表代码（HTML 被覆盖），再运行一次 `python add_nav.py` 即可重新生成导航。

## 目录结构

```
excel-charts/
├── index.html              # 全部图表总览页
├── requirements.txt
├── chapter2/               # 第二章 静态图表 30 张
│   ├── chart01_渐变柱形图.py
│   ├── chart02_带均值柱形图.py
│   └── ...（chart01~chart30）
├── chapter3/               # 第三章 动态图表 7 张（Timeline 自动播放）
│   └── chart01~chart07
├── chapter4/               # 第四章 数据大屏 2 个
│   ├── chart01_人力资源看板.py
│   └── chart02_销售数据大屏.py
└── output/                 # 生成的 HTML（运行时自动创建）
```
