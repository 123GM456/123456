## 一、项目概览

| 项目 | 内容 |
| --- | --- |
| 选题 | 基于世界银行开放数据的全球宏观经济分析（宏观经济方向，主题三） |
| 数据源 | 世界银行 WDI（World Development Indicators）官方数据包，8 个指标 |

| 复现 | `python run_all.py` 一键重跑全部结果 |

### 一句话结论

全球增长中枢缓慢下移，中国「增速差收窄但份额仍升」（份额 3.64% → 16.93%），
全球产出高度集中但集中度在下降（前十 73.82% → 67.22%），增量在地理上正从 G7 向亚太与新兴市场扩散。

## 二、四个核心业务问题

1. **趋势**：过去 25 年全球增长的中枢在哪？波动来自何处？中国的增速差是否在收窄？
2. **结构**：全球产出是否「少数国家撑起大半边天」？集中度在升还是在降？
3. **定位**：按「份额 × 增速」各国处在什么象限？按六维特征聚类，世界自然分成几类？
4. **预测**：中国 2025—2027 年经济规模会到什么水平？不确定性多大？历史上预测准不准？

## 六、分析模型与核心结论

| 模型 | 方法要点 | 核心结论 |
| --- | --- | --- |
| **M1 趋势对比** | 以「上年 GDP 现价」为权计算全球加权增速（避免小国等权扭曲） | 三个十年段均值 2.41% / 3.08% / 2.53%；2024 年中国 4.96%、全球 2.86%，**增速差 +2.10 pct**；中国份额 3.64% → **16.93%** |
| **M2 帕累托 ABC** | 累计份额 ≤70% 为 A、70—90% 为 B、>90% 为 C | 200 国中前 10 国占 **67.22%**，**19 国**覆盖 80%；A 类 12 国占 70.89%，C 类 163 国仅占 10.22% |
| **M3 波士顿矩阵** | 横轴 2024 份额中位数（3.98%），纵轴 2015—2024 复合增速的**全球加权均值**（2.74%） | 明星 38 / 金牛 62 / 问题 45 / 瘦狗 54；中国（16.93%、5.77%）、印度、印尼在明星象限，**印度增速已略高于中国但份额仅 1/5** |
| **M4 K-Means 聚类** | 六特征 z-score 标准化，k 由轮廓系数 + 肘部法共同确定 = **5**（0.2817） | 高增长追赶型 64（含中国）/ 成熟稳健型 61（含美国）/ 高失业低增长型 23 / 外向型高开放 16 / 增长失速型 7 |
| **M5 Holt 预测** | 加性 Holt，α、β 网格搜索（α=0.75、β=0.15）；95% CI 用 σ√h·1.96 | 2025—2027 点预测 **19.71 / 20.51 / 21.31 万亿美元**；MAPE **7.65%**；**回测误差逐年放大且系统性高估**（1.75% → 8.68% → 12.53%），因模型无法吸收汇率因素 |
| **M6 结构演变** | 区域 / 收入分组份额时序 + 前十集中度 | 北美 32.73%→28.55%，欧洲中亚 29.98%→26.53%，东亚太平洋 24.23%→**28.35%**；前十集中度 **73.82% → 67.22%**；低收入 25 国合计仅 0.49% |

### 参数与阈值的业务依据（摘）

- **M1 加权而非简单平均**：简单平均会让图瓦卢与美国的增速等权，2020 年全球曲线会被小国噪声主导。
- **M2 用 70%/90%**：帕累托通用分界，对应「保基本、抓重点、放长尾」的资源分配三段式。
- **M3 纵轴用加权均值而非中位数**：中位数只答「比一半国家快」，加权均值才对应 BCG 中「行业增长率」的角色。
- **M4 取 k=5 而非最大值 6**：k=6 的轮廓系数（0.2812）与 k=5 几乎相同，但多切出的一簇不增加业务可解释性。
- **M4 命名用规则阶梯而非按人均 GDP 排序**：排序命名会把「负增长的危机国」与「低收入高增长国」混为同类。
- **M5 训练起点 2005 年**：2000—2004 年中国入世初期低基数跳变会让趋势项高估，回测 MAPE 从 12.07% 降至 **7.65%**。

## 八、数据清洗与治理要点

1. **剔除区域聚合体**：利用国家元数据表 `Region` 为空的特征识别聚合体（世界、东亚与太平洋等），
   共剔除 **25 872 行**，避免全球 GDP 被重复计算。
2. **年份裁剪**：保留 2000—2024，剔除 **71 176 行**。
3. **规则型异常值**：7 个指标设硬阈值（如 GDP 增长率 ±50%、贸易占比 0—500%），命中 **35 个** 置缺失。
4. **统计型离群点**：3×IQR 规则标记 **1 388 个**，**只标记不删除**——宏观极端值多为真实事件，
   删除会让「全球增长波动」这一结论失真。
5. **缺失值不插补**：政府债务缺失率 **78.95%**，属结构性缺失（多数国家不披露该口径），
   任何插补都会凭空制造「债务水平」信号，故仅做有值样本的描述统计。

整体缺失率 17.72%：总人口 0% / GDP 现价 3.37% / 增长率 4.74% / 失业率 13.99% / 贸易 17.97% / 债务 78.95%。

  已 grep 验证 22 个 HTML 均无外链——保证断网、离校答辩时图表照常显示。
- **单点取数**：所有图表与论文数字只从 `outputs/models/conclusions.json` 读取，杜绝「图文对不上」。
- **手写 K-Means / Holt**：环境无 sklearn / statsmodels 也不影响复现，且过程可解释、可审计。
- **双引擎出图**：交互图用 pyecharts（矢量 HTML，可悬停、可联动），论文静态图用 Matplotlib
  （150 dpi PNG，中文字体走系统微软雅黑），两者读取同一份 `outputs/models/` 结果，确保图文一致。

## 十一、局限与展望

- **维度局限**：8 个指标只刻画规模与增长，未含产业结构、人口年龄结构、制度质量；
  后续可引入研发投入、教育年限、营商环境与治理指标。
- **方法局限**：Holt 为单变量趋势外推，无法纳入汇率、通胀、政策等外生变量；
  应改用 ARIMAX / VAR / 结构性模型，并对不变价与现价分别建模。
- **数据局限**：债务指标缺失 78.95%，可改用 IMF 公共债务数据库补全。
- **可比性局限**：美元现价比较受汇率波动影响（M5 的回测误差正是其体现）；
  若改用 PPP 口径，「低收入仅占 0.49%」的判断需重新审视。
