## 一、数据来源

本项目全部数据来自**世界银行开放数据（World Bank Open Data）** 旗下的
**世界发展指标（World Development Indicators, WDI）** 数据库。

- 官方平台：https://databank.worldbank.org/source/world-development-indicators
- 数据文件名：`API_<指标代码>_DS2_EN_csv_v2_<id>.zip`（世行 API v2 导出命名）
- **获取日期：2026 年 10 月 28 日**（8 个指标包同日获取）
- **数据版本：2026-10-08**（各 CSV 内 `Last Updated Date` 字段一致）
- 许可协议：**CC BY 4.0**（知识共享 署名 4.0 国际），允许复制、分发、修改与商业使用，只需署名。
- **抽样说明：未抽样**，217 个经济体 × 2000—2024 年全量使用，未设置随机种子。
- 获取方式：在官方数据平台按指标逐个下载 CSV 数据包，共 8 个指标包；
  每个包内含数据文件（`API_xxx_DS2_EN_csv_v2_xxxx.csv`）、国家元数据
  （`Metadata_Country_xxx.csv`）与指标元数据（`Metadata_Indicator_xxx.csv`）。
- 原始文件原样保存在项目 `data/raw/` 目录下，**未做任何手工修改**；所有清洗逻辑以代码形式
  写在 `scripts/01_load_clean.py` 中，可逐条审计。

### 纳入的 8 个指标

| WDI 代码 | 指标名称 | 单位 |
| --- | --- | --- |
| NY.GDP.MKTP.CD | GDP（现价美元） | 美元 |
| NY.GDP.MKTP.KD.ZG | GDP 增长率（不变价） | % |
| NY.GDP.PCAP.KD.ZG | 人均 GDP 增长率 | % |
| SP.POP.TOTL | 总人口 | 人 |
| NE.TRD.GNFS.ZS | 货物与服务贸易占 GDP 比重 | % |
| NE.EXP.GNFS.ZS | 出口占 GDP 比重 | % |
| GC.DOD.TOTL.GD.ZS | 中央政府债务占 GDP 比重 | % |
| SL.UEM.TOTL.ZS | 失业率（ILO 估算） | % |

> WDI 未提供现价人均 GDP 的独立指标包，本项目由「GDP 现价 ÷ 总人口」派生，
> 口径与 `NY.GDP.PCAP.CD` 一致。

   缺失值不插补等策略，均在 `scripts/01_load_clean.py` 的注释与论文第三章中明确说明，

## 四、缺失与异常处理的原则性说明

- **政府债务占 GDP 比重缺失率 78.95%**：属结构性缺失——多数国家按年披露中央政府债务存在滞后，
  且「中央 vs 一般政府」口径在各国差异很大。因此本项目**不插补**该指标，
  也**不用它做跨国排序**，仅在描述性统计中展示其分布。
- **3×IQR 离群点只标记不删除**：宏观数据中的极端值往往对应真实事件（2020 年疫情负增长、
  战争导致的经济崩溃、资源型国家出口骤变），它们恰恰是分析要解释的对象；
  删除会让「全球增长波动」这一结论失真。标记以 `outlier_iqr` 布尔列随数据保留，供模型按需选择。
- **区域聚合体识别方法**：利用国家元数据表中 `Region` 字段——主权国家非空、聚合体为空，
  据此剔除 25 872 行，避免全球 GDP 被重复计算。
